## C03 清除数据可能遗留Android原生副本

硬性要求存在缺口。已在合规副本修复并完成相应验收。

原版依据 `Drama Alarm Android 11.0/app/src/main/assets/web/app.js:2373-2392；app/src/main/java/com/dramaalert/android/AlarmScheduler.java:47-61,259-279`。

## Android补充修复

1. A01 RingingService.notification added fullScreenIntent to non-ringing wake-check notifications. Only ringing notifications may request full-screen presentation; wake-check confirmation is an ordinary notification. 文件 `android/app/src/main/java/com/dramaalert/android/RingingService.java`。

1. A02 Exported launcher trusted from_alarm/alarmId/payload extras to show over lock screen and keep display awake. Only durable private scheduler state may enable alarm-window presentation. 文件 `android/app/src/main/java/com/dramaalert/android/MainActivity.java`。

1. A03 Alarm notifications used VISIBILITY_PUBLIC, exposing the personal alarm label on locked screen. Use VISIBILITY_PRIVATE so system privacy settings can redact private content. Explicit cloud-backup/device-transfer exclusions accompany allowBackup=false. 文件 `android/app/src/main/java/com/dramaalert/android/RingingService.java`。

1. A04 Bundled WebView had no per-response CSP and origin checks did not reject user-info or alternate ports. Explicit HTTPS/host/port/path allowlist and CSP excluding remote scripts/frames, no file/content access or automatic windows. Bundled legal-page return links resolve the local root to index.html. 文件 `android/app/src/main/java/com/dramaalert/android/MainActivity.java`。

1. A05 Local reset cleared Web state without clearing native pending/handled/stopped events and personal schedule mirror. Add native clearLocalData bridge, cancel all registrations, stop audio, clear this variant native preferences, and wire Web reset. 文件 `android/app/src/main/java/com/dramaalert/android/AlarmScheduler.java`。

1. A06 Permission grant broadcast was not handled for SCHEDULE_EXACT_ALARM on API31/32. Listen for ACTION_SCHEDULE_EXACT_ALARM_PERMISSION_STATE_CHANGED and reschedule using actual permission state. 文件 `android/app/src/main/java/com/dramaalert/android/AlarmReceiver.java`。

1. A07 Same applicationId would replace installed original debug app. Independent package and preferences for side-by-side demo installation. 文件 `android/app/build.gradle`。
